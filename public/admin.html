📝 Google Sheets連携の設定方法

  1. Google Sheetsを作成
  2. Spreadsheet IDをコピー（URLの /d/ と /edit の間）
  3. タブ名を決定（例：「使用履歴」）

📱 チャネル設定ガイド

Telegram Bot
  1. BotFatherで/newbotを実行してBot作成
  2. Bot Token（例: 123456:ABC-DEF...）をコピー
  3. 上記「+ Telegram Bot」から追加
  4. Webhook URLをコピー
  5. 設定コマンド実行：
    curl https://api.telegram.org/bot<TOKEN>/setWebhook -d "url=<WEBHOOK_URL>"
LINE Bot
  1. LINE Developers でMessaging APIチャネル作成
  2. Channel SecretとChannel Access Tokenをコピー
  3. 上記「+ LINE Bot」から追加
  4. Webhook URLをLINE DevelopersのWebhook設定に貼り付け
  5. Webhook利用を「有効」に設定

❓ AIキャラクター設定の使い方
📌 キャラ設定方法:
1. プリセット（ひかり/まさと/あおい）をクリックで基本設定を読み込み
2. 各項目をカスタマイズ（口調・一人称・絵文字など）
3. 「💬 プレビュー」で応答イメージを確認
4. 「保存」で確定

💡 プリセットの説明:
・ひかり: フレンドリーで明るい女性。絵文字多め。初心者ユーザー向け。
・まさと: 丁寧で落ち着いた男性。フォーマル。VIPユーザー向け。
・あおい: 知的でクール。簡潔。テクニカルな問い合わせ向け。

❓ 担当者設定の使い方
📌 担当者の追加方法:
1. 「+ 担当者を追加」ボタンをクリック
2. 名前・メール・役割を入力
3. AIキャラクターを割り当て（先にAIキャラクター画面で作成）
4. 担当チャネルとシフトを設定
5. 「保存」で確定

💡 シフト管理:
・「営業時間内」は営業時間設定に連動
・「24時間」は常時対応
・ステータスは手動で切り替え可能
