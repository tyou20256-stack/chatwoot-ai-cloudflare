## 投入時のルール（重要）

### 含めない情報（金銭事故・規制リスクのため除外）
- **具体的な金額**（最低/最高入金額、ボーナス金額、出金上限）
- **ボーナスコード文字列**（架空コード生成リスク）
- **キャンペーン期間・終了日**
- **個別の倍率・賭け条件の数値**
- **特定機種の還元率（RTP）の具体値**
- **時間限定オファーの詳細**

### 含めてよい情報
- 機能の存在・概念説明
- 一般的な手順（具体値ナシ）
- ポリシー・規約の方針
- トラブル切り分けの一次質問
- 用語の定義

### 回答スタイル
- 具体値が必要な質問には「正確な情報はメニューから確認してください」と誘導
- 入金フロー中の質問は「現在進行中の手続きを完了させてください」とフロー優先
- 不確実な質問は「サポートにお問い合わせください」とエスカレーション
