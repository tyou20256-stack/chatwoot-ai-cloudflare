# 入金について（一般）

## 対応している入金方法

スロット天国では以下の入金方法に対応しています。具体的な手順や条件は、チャットメニューの「💰 入金・出金」からご確認ください。

- 銀行振込
- 仮想通貨（Bitcoin、Ethereum等）
- PayPay（マネー / マネーライト）
- コンビニ入金
- ATM入金

## 入金処理の流れ

入金方法によって流れが異なりますが、概ね以下のステップとなります。

1. チャットメニューから入金方法を選択
2. ご希望の入金額を選択または入力
3. 表示される指示に従って送金
4. 取引番号や入金確認スクリーンショットを送付（方法による）
5. サポートにて確認後、アカウントに反映

## 入金が反映されない場合

入金が反映されない場合は、以下をご確認ください。

1. 送金は完了していますか
2. 取引番号やスクリーンショットをチャットに送付しましたか
3. 送金から十分な時間が経過していますか（処理時間は決済方法により異なります）

上記を確認しても反映されない場合は、取引番号と送金日時を添えてオペレーターへお問い合わせください。

## 入金時にエラーが出る場合

入金時にエラーが出る場合は、以下をお試しください。

1. ブラウザを再読み込みする
2. 別のブラウザで試す
3. 通信環境を確認する
4. ご利用の決済サービス側に制限がかかっていないか確認する

解決しない場合はオペレーターまでご連絡ください。

## 入金フローを途中でキャンセルしたい

入金手続きの途中でキャンセルが必要な場合は、すぐにオペレーターへご連絡ください。状況により対応が異なります。

## 重要な注意

具体的な入金額の上限・下限、処理時間、手数料等は、チャットメニューの該当項目から最新情報をご確認ください。
