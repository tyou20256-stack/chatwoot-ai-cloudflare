# トラブル一次切り分け

## ログインできない

1. メールアドレス／電話番号は正しいですか
2. パスワードの大文字・小文字に間違いはありませんか
3. パスワードリセットを試しましたか
4. 上記で解決しない場合はオペレーターへ

## サイトが表示されない / 重い

1. ブラウザの再読み込み（リロード）を試してください
2. ブラウザのキャッシュをクリアしてみてください
3. 別のブラウザ（Chrome、Safari、Firefox等）で試してください
4. 通信環境を確認してください
5. それでも改善しない場合はオペレーターへ

## 入金が反映されない

1. 送金は完了していますか
2. 取引番号やスクリーンショットをチャットに送付しましたか
3. 送金から十分な時間が経過していますか（決済方法により異なる）
4. ボーナスコード申請等、別の手続きが進行中ではありませんか
5. 上記を確認しても反映されない場合は、取引番号と送金日時を添えてオペレーターへ

## 出金できない

1. 出金条件（賭け条件等）は達成していますか
2. ボーナスを利用中ではありませんか
3. アカウント情報の確認待ちではありませんか
4. 出金方法側のメンテナンス・障害情報を確認してください
5. 不明な場合はオペレーターへ

## ゲーム中の不具合

1. 該当ゲームを一旦閉じて再度入り直してください
2. ブラウザを再読み込みしてください
3. ブラウザのキャッシュをクリアしてください
4. 別のブラウザで試してください
5. それでも解決しない場合は、発生日時と機種名を添えてオペレーターへ

## ボーナスが付与されない

1. キャンペーンの参加条件を満たしていますか
2. ボーナスコードの申請は完了していますか
3. 入金が必要なキャンペーンの場合、入金は反映されていますか
4. 付与スケジュールに到達していますか（即時ではなく特定日時の場合あり）
5. 上記を確認しても付与されない場合はオペレーターへ

## 残高がおかしい

残高に不審な点がある場合は、すぐにオペレーターへご連絡ください。日時、操作内容、可能であればスクリーンショットをお送りいただくとスムーズです。

## 通信エラーや決済エラー

決済時にエラーが出た場合は、画面のスクリーンショットとエラーメッセージをお送りください。再試行して二重決済にならないよう、必ずサポートに状況を確認してから操作を続けてください。

## オペレーターへの連絡が必要な状況

以下の状況では、まずオペレーターへご連絡をおすすめします。

- 残高に不審な点がある
- 二重決済の可能性がある
- ログインできない
- 出金が長期間処理されない
- 不審なメール・通知を受け取った
- 自分以外がアカウントを操作した形跡がある
