# スロット・カジノ用語集

## 入金・出金関連

| 用語 | 意味 |
|------|------|
| 入金 / デポジット | アカウントに資金を追加する |
| 出金 / 引き出し | アカウントから資金を引き出す |
| FTD | First Time Deposit。初回入金のこと |
| 着金 | 送金が相手側で受領完了すること |

## ボーナス関連

| 用語 | 意味 |
|------|------|
| ボーナスコード | キャンペーン参加申請に使う識別コード |
| 入金不要ボーナス | 入金せずに受け取れるボーナス |
| 入金ボーナス | 入金時に付与されるボーナス |
| 賭け条件 / WR / 倍率 | ボーナスを出金するために達成すべきベット総額の倍率 |
| 没収 | ボーナスや勝利金が無効になること |
| キャッシュバック | プレイ実績に応じた還元 |

## ゲーム関連

| 用語 | 意味 |
|------|------|
| スロット | リール式のゲーム |
| ビデオスロット | ビデオ画面のスロット（現代の主流） |
| ペイライン | 配当が成立する並び |
| ボーナスBUY / FS BUY | フリースピンやボーナスゲームを購入する機能 |
| フリースピン / FS | 無料で回せるスピン |
| BUY額 | ボーナスBUYに使う購入金額 |
| ベット | 1スピンに賭ける金額 |
| 配当 / 配当倍率 | 当選時に支払われる金額 / その倍率 |
| RTP | Return To Player。プレイヤーへの還元率 |
| プロバイダー | ゲーム提供会社（Pragmatic Play等） |
| ライブカジノ | 実際のディーラーが進行するゲーム |

## アカウント・本人確認関連

| 用語 | 意味 |
|------|------|
| KYC | Know Your Customer。本人確認手続き |
| アカウントID / ユーザー名 | スロット天国でのお客様の識別ID |
| Chat ID | チャット上での識別ID |

## キャンペーン関連用語

| 用語 | 意味 |
|------|------|
| プロモーション | 期間限定の特典企画 |
| キャンペーン | プロモーションと同義 |
| ステージ達成 | 段階的なミッションをクリアすること |
| エントリー | キャンペーンへの参加申請 |
| 条件達成 | キャンペーンの要件を満たすこと |
