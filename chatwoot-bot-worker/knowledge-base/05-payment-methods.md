# 対応している決済方法

## 入金方法（一覧）

| 方法 | 概要 |
|------|------|
| PayPayマネー | PayPayからの送金。即時～短時間で反映されることが多い |
| PayPayマネーライト | PayPayからの送金（マネーライト残高） |
| 銀行振込 | 国内銀行口座から振込 |
| コンビニ入金 | コンビニ店頭でお支払い |
| ATM入金 | 提携ATMから入金 |
| 仮想通貨 | Bitcoin、Ethereum等 |

## 出金方法（一覧）

| 方法 | 概要 |
|------|------|
| 銀行振込 | ご登録の国内銀行口座へ振込 |
| 仮想通貨 | 指定のウォレットアドレスへ送金 |
| PayPay | PayPayへ送金 |

## PayPayマネーとマネーライトの違い

PayPayには「マネー」と「マネーライト」の2種類の残高があります。

- **PayPayマネー**: 銀行口座と紐付いた本人確認済みの残高
- **PayPayマネーライト**: 本人確認なしでも利用可能な残高

スロット天国ではどちらにも対応しています。お使いの残高種類に合わせてメニューから選択してください。

## 銀行振込について

国内主要銀行に対応しています。送金時の指定情報（振込先、振込人名）はチャットの自動案内に従ってください。送金完了後は、取引番号やスクリーンショットをチャットでお知らせください。

## 仮想通貨について

主要な仮想通貨に対応しています。送金時のネットワーク選択にご注意ください。送金後の着金確認には、ブロックチェーンの承認時間がかかる場合があります。

## コンビニ入金について

コンビニ入金は、決済番号を発行してコンビニ店頭でお支払いいただく方式です。発行された決済番号をコンビニのレジまたは端末でご入力ください。

## ATM入金について

ATM入金は、ご希望の入金額をチャットでお伝えいただいた後、サポートからご案内いたします。

## 重要な注意

各決済方法の最低／最高金額、手数料、処理時間は、チャットメニューから最新情報をご確認ください。
